# Briks

Briks é um aplicativo para Windows de **chamadas de voz e transmissão de tela** entre amigos. Você entra numa sala, fala, mostra a tela e conversa, sem gravação e sem anúncios.

- **Para maiores de 18 anos.** O Briks confere a idade na entrada.
- **Login com Google ou Discord.** Você não cria outra senha.
- **Chamadas sem gravação.** O áudio, o vídeo e a tela passam em tempo real, direto entre os amigos ou por um servidor que só repassa.
- **Código aberto** (AGPL-3.0): [github.com/ygorbetine/Briks](https://github.com/ygorbetine/Briks).

## Por que o Briks pede sua data de nascimento no Google

O Briks é só para maiores de 18 anos. Ao entrar com Google, o app lê **uma vez** a data de nascimento da sua conta (permissão `user.birthday.read` da People API do Google) apenas para saber se você tem 18 anos ou mais. A data **não é guardada**: o app guarda somente que sua conta foi confirmada como adulta. Se sua conta Google não tiver data de nascimento com ano, o Briks pede que você a preencha em [myaccount.google.com/birthday](https://myaccount.google.com/birthday).

O uso das informações recebidas das APIs do Google pelo Briks segue a [Política de Dados de Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado.
